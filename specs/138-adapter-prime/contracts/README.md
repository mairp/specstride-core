# Contracts of feature 138

Data of the prime harness adapter, read by the tests and by the build. Where a file here and
`spec.md` differ, `spec.md` stands. Where a file here and feature 100 differ, feature 100 stands.

| File | Content |
|---|---|
| `argument-table.json` | Exact flags and variables at the pin, per role and mode |
| `dialect-row-prime.json` | The row `prime` of the dialect table (`specstride.stream-dialect/1`) |
| `descriptor-prime.json` | The harness descriptor as data (`descriptorVersion: 1`) |
| `reader-records.json` | Record type of the stream, normalized record, projected event, display line |
| `diagnostics.json` | Codes, severities, messages and extras of the reader |
| `classifier-entries.json` | Entries for the quota classifier |
| `parity-rows.json` | Rows and settings of the `parity` profile that this feature uses |
| `capture-plan.json` | The five captures and the two probes |
| `traceability.json` | Cluster and item to requirement and test |

No file names a launcher, variant, model or gateway of the owner's machines.
