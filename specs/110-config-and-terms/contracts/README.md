# Contracts of feature 110

`config-keys.tsv` is a machine-readable copy of the tables of `spec.md` §K.3 to §K.6b, one key per line, generated from them and checked by task T004: exactly the keys of the catalogue, no others. The count is 259, as T004 requires ("the file holds exactly those 259 keys"). §K.6 also lists four keys of feature 107 — `derive.stageTimeoutSec` and the three `verification.scopes.<commandId>.*`, the last three named by F110-FR-019 — which the catalogue does not carry: they belong to feature 107's own contract, and no owner ruling amends T004's count. They are named with that reason in `EXCLUDED_KEYS` of the generator, which reports a problem when one of them is in no table of §K.3 to §K.6b, when one gains a source row, or when one appears in this file, so the count cannot drift either way. The difference is reported to the orchestrator with the register rows W-ORC-01 to W-ORC-03. The old spelling of every correction and withdrawal of §K.9 is recorded in the `confirmed_or_corrected` column of the standing key, not as a row of its own. The tables in `spec.md` stand where the two differ. The generator is `packages/config/tools/config-keys-gen.ts` (`--check` compares, no argument writes); the two columns the tables do not carry, `proposed_by` and `confirmed_or_corrected`, come from `packages/config/data/config-keys-sources.json`. Its columns: `key`, `type_and_range`, `default`, `value_under_parity`, `trust_class` (with the snapshot class in parentheses), `owner_feature`, `proposed_by`, `confirmed_or_corrected`, `layers`, `profile_row` (the number of the row of annex X §X.7, empty when the key has no row).

`alias-table.tsv` is the alias data that task T005 keeps complete: 159 rows, one per as-is variable, in the order of the environment alias table of annex X §X.8 first, then the aliases that only this feature holds (§K.8), then the variables that reach no key and those that are not carried. The table of annex X §X.8 stands where the two differ. The terms rows moved to feature 147. The check is `packages/config/tools/alias-coverage.ts` with `packages/config/tests/unit/alias-table.test.ts`: every as-is variable the 226 items of kind `env` of `docs/ecosystem/research/R18-behaviour-inventory.tsv` name has a row, except the six that only the nine items of DV-064 name.
