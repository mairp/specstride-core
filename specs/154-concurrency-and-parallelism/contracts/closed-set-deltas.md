# Closed-set deltas proposed by spec 154 — ALL PROPOSALS

Every row below is a **proposal**, decided by the answered rulings of the spec ("Clarifications",
"Closed sets") and of stage 1 (CQ-154-02 to -10). This file changes no register, no schema and no
spec of another feature (F100-FR-212). Rows are written for the owner to copy into
`docs/ecosystem/consolidation.md` and the data files of `packages/contracts/`. Until a row is
copied, the behaviour behind it does not land, or lands only as the spec's stated fallback.

No DV number is assigned here: the register (`docs/ecosystem/consolidation.md` §6) ends at
DV-120 while `specs/141-parity-oracle/contracts/register-map.json` already carries rows to
DV-122. That drift is reconciled first; the rows below take the next free ids after that.
