# Contracts of feature 130

Machine-readable forms of what `spec.md` states. Where a file and the spec differ, the spec
stands. Facts carry the pin `0.1.0-rc.8` and a `verified-on` date or the word `unverified`.

| File | Content |
|---|---|
| `argument-table.json` | Flags and variables of the harness per use |
| `descriptor-dsh.json` | The harness descriptor as data |
| `critic-patch.json` | The 18 tool ids of the deny list |
| `classifier-entries.json` | Entries for the quota classifier |
| `plugin-request.schema.json` | `specstride-dsh-plugin-request/v1` |
| `plugin-receipt.schema.json` | `specstride-dsh-plugin-install/v1` |
| `parity-rows.json` | Rows and settings of the `parity` profile |
| `capture-plan.json` | The six captures |
| `traceability.json` | Behaviour items and clusters to requirements and tests |
