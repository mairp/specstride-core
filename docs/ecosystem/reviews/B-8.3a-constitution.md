# B-8.3a — Constitution review: plans of features 100 to 109

Reviewer: independent agent. Date: 2026-09-29.

Scope: the plans of `specs/100-specstride`, `101-gate-and-verdict`, `102-run-control`,
`103-proposer-pass`, `104-spec-input`, `105-verification`, `106-learning`, `107-launch-contract`,
`108-reverse` and `109-harness-seam`, against `.specify/memory/constitution.md` v3.0.0 and the
Constitution Check of `.specify/templates/plan-template.md`.

Method: the constitution, the template and all ten `plan.md` files were read in full. `tasks.md`,
`research.md`, `data-model.md`, `quickstart.md` and `spec.md` were read by extraction (`grep`, and
small Python scripts over `plan.md` and over `contracts/data/layout.json` and
`package-graph.json` of feature 100), then the places that matter were read. Each finding was checked
against the file it cites. Rulings were read in `docs/ecosystem/APPROVAL.md` (18, 50, 56, P1 to P16);
queued questions in `docs/ecosystem/CLARIFY-QUEUE.md`; the divergence register in
`docs/ecosystem/consolidation.md`.

| Severity | Count |

What holds: every plan has the Constitution Check with twenty rows in the template's order; no plan
admits a violation, so no waiver of a NON-NEGOTIABLE principle exists; language, runtime and test
runner are the same in all ten plans; no task builds a watcher, a database as source of truth, a
native module, a write to the consumer's real home, or a commit or revert outside ruling 50 and
ruling P1; parity tests and characterization tests are required tasks in all ten features, and every
extraction from Lisa has a characterization task.

The three most serious findings:

1. B-8.3a-001 (critical): the proof "by pinned configuration" of a tool-less critic departs from the
   text of Principle IX, and neither plan 100 nor plan 109 records it in Complexity Tracking.
2. B-8.3a-002 (high): the canonical hasher is built by feature 104 in `@specstride/spec-formats`,
   while the package graph and four plans take it from `@specstride/kernel`; the core cannot import
   the package where it is built.
3. B-8.3a-003 (high): feature 107 builds a package `packages/launch-contract` that the package graph
   of feature 100 does not hold; the graph and plan 123 place feature 107 in `@specstride/pipeline`.
