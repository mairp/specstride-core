# B-8.3b — Constitution review: plans of features 110 to 119

Reviewer: independent agent. Date: 2026-09-29.

Scope: the plans of features 110, 111, 112, 113, 115, 116, 117, 118 and 119 against the constitution
v3.0.0 (`.specify/memory/constitution.md`), the Constitution Check of
`.specify/templates/plan-template.md`, the plan of feature 100 and its package graph
(`specs/100-specstride/contracts/data/package-graph.json`).

Method: the constitution, the template, the plan of feature 100 and the nine plans were read in full.
`research.md`, `data-model.md`, `spec.md` and `tasks.md` were read where a row of a check or a finding
needed them. Extraction with `grep` and small shell loops: requirement ids cited in a plan against the
ids defined in its spec; register rows (`DV-nnn`) cited in a plan against the `divergence:` fields of
its spec and against `docs/ecosystem/consolidation.md`; counts of `PT-` and `CT-` tests, of rows of each
Constitution Check and of N/A marks; a search of the nine task lists for another language, a watcher,
a service, a write to a real home, a commit or a revert, and paid calls; a search of all plans for named
libraries. `docs/ecosystem/CLARIFY-QUEUE.md` and `docs/ecosystem/STAGE-B-F100-AMENDMENTS.md` were
searched before each finding; what is already queued or listed there is not a finding.

What holds. All nine plans have a Constitution Check with twenty rows, I to XX, none unchecked. Every
plan states TypeScript 5.x strict on Node.js 22 or later, the test runner that Node ships, no native
module and no install script; none adds a second product language, and the Language Ledger stays
empty. No task builds a watcher or a service in the control path, none writes to the consumer's real
configuration home, and none commits to or reverts the project's repository (feature 115 tests the
opposite, `CT-115-17` and `CT-115-160`). Parity and characterization tests are required tasks in all
nine task lists; no task is marked optional. Feature 116 has its own complete check: every requirement
it cites is an `F116-FR` id that its spec defines.

The three most serious findings:

1. B-8.3b-001 (critical): feature 113 gates every pull request on a skill-trigger suite that calls a
   model, and schedules nightly and weekly paid runs, while its check of Principle XII says that no
   per-change job makes a paid call. No Complexity Tracking entry records it.
2. B-8.3b-002 (high): feature 111 builds a package `events` that the package graph of feature 100 does
   not hold; the graph puts the redactor in the kernel, where features 117 and 119 look for it.
3. B-8.3b-003 (high): features 110, 111, 112 and 113 place the conformance suite of their extension
   point outside the published test kit, against F100-FR-017.
