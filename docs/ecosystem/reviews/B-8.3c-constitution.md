# B-8.3c — Constitution review: plans of features 122 to 131

Reviewer: independent agent. Date: 2026-09-29.

Scope: the plans of features 122, 123, 124, 125, 126, 127, 128, 129, 130 and 131 against
`.specify/memory/constitution.md` v3.0.0 (Principles I to XX, Additional Constraints, Development
Workflow and Quality Gates, Governance), the Constitution Check of
`.specify/templates/plan-template.md`, the plan of feature 100 and
`specs/100-specstride/contracts/data/package-graph.json`.

Method: the constitution, the template, the plan of feature 100 and the ten `plan.md` files were read
in full. `spec.md`, `tasks.md`, `research.md` and `contracts/` of each feature were read at the places
that a plan row cites or that a check needs, found with `grep`. Rulings 1, 2, 6, 18, 36, 43, 57, 57a,
59, 63, 67, 70, D1, P14 and P15 were read in `docs/ecosystem/APPROVAL.md`. The divergence register
(`docs/ecosystem/consolidation.md`, DV-001 to DV-113) and `docs/ecosystem/CLARIFY-QUEUE.md` (rows of
features 122 to 131) were read to tell a finding from a queued question. No file but this report was
written. No CLI of a harness was run.

What holds: all ten plans have a Constitution Check that answers the twenty principles; all ten state
strict TypeScript on Node.js 22 or later, no native module and no dependency from npm beyond the
validator that feature 100 chose and the optional, unbundled Agent SDK of ruling 70; none adds a
second language to the product; every feature has test tasks, and every feature with carried as-is
behaviour has parity tests as required tasks; every adapter has a fake-binary test and a replay of
recorded streams; the exceptions of rulings 57, 57a, D1 (131) and P15 (130) are used inside their
limits; ruling 6 is followed by 123 (`relaunch.owner` is `root` by default and `supervise` under
`parity`).

The three most serious findings:

1. B-8.3c-001 (critical): the dsh adapter does not switch auto-loaded context off for a pass, which
   Principle VIII, ruling 36 and F100-FR-113 require, and the plan records it as a pass with no row in
   Complexity Tracking.
2. B-8.3c-002 (high): feature 126 plans two packages, `stream-seam` and `invocation`, that the package
   graph of feature 100 does not hold; the graph puts 126 in `@specstride/harness`.
3. B-8.3c-003 (high): feature 128 plans a package `telemetry`; the package graph puts 128 in
   `@specstride/observability`.
