# B-8.2d — Consistency: event names and closed sets

Reviewer: independent agent. Date: 2026-09-29.

Scope: event type names and payloads, the event envelope, the closed sets of annex X §X.6 (owners
and members), the threat model of §X.9, and the one redaction point, across `spec.md`, `plan.md`,
`tasks.md`, `data-model.md` and `contracts/` of the 41 features.

Method: seven small Python scripts and `grep`, kept in the scratch directory `B-8.2d/`.

| Script | What it extracts |
|---|---|
| `ev.py` | Every backticked dotted token of every feature, compared with `specs/111-event-schema-and-projection/contracts/event-catalogue.tsv` (109 types) |
| `proj.py` | Every field of `specs/144-compatibility-projection/contracts/projection-table.tsv` (125 rows), compared with the `data` fields of the catalogue and the envelope |
| `legacy2.py`, `fields.py` | Every as-is event name a feature cites, and the fields it states, compared with the projection rows |
| `prose.py` | Every requirement that demands an event without naming a type (80 places) |
| `cs.py`, `members.py` | The 270 rows of §X.6 against `closed-sets.json`, against the owner's spec, and against the "Closed sets" table of every feature |
| `near.py` | Uses and near-miss spellings of the values of 17 widely used sets |
| threat script (inline) | Every T-nn of §X.9 against the files of each owner |

Every finding below was read in the file before it was written down.

## Summary

| Severity | Count |
|---|---|
| critical | 0 |
| high | 7 |
| medium | 11 |

What holds: every dotted event type that any feature names in backticks is in the catalogue, with
the same spelling (0 unknown types in 40 features). Every catalogue type has a projection row.
All 65 as-is names that features cite are targets of a projection row. The 270 rows of §X.6 equal
`closed-sets.json` row for row, every owner named exists, and the six sets moved by the splits
(rows 27, 62, 64, 65, 66, 184) have their members in the specs of 116 and 143. No feature states
the envelope fields, `seq` or the rule for unknown fields differently from §X.1, with the two
exceptions of feature 126 below.

The three most serious findings:

1. B-8.2d-001: the result values of `microloop.unit` in feature 111 (`keep`, `repair`, `escalate`) are not the members of row 136 that feature 115 writes (`kept`, `repair`, `unresolved`).
2. B-8.2d-002 and -003: feature 126 ships an event to sinks when the primary write failed, and strips `ts` from what a sink receives; feature 111 and §X.1 forbid both.
3. B-8.2d-006: at least eight events that requirements demand have no type in the catalogue, while F111-FR-001 and F111-FR-020 make the writer drop an event without one.
