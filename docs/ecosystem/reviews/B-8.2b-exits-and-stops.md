# B-8.2b — Consistency: exit codes and stop reasons

Reviewer: independent agent. Date: 2026-09-29.

Scope: `spec.md`, `plan.md`, `tasks.md` and `contracts/` of the 40 features `specs/101-*` to
`specs/149-*` (328 files), checked against feature 100 annexes E, F, G, C §C.13 and X §X.6, the
generated `contracts/data/exit-codes.json`, `stop-reasons.json`, `run-state-machine.json`,
`cli-protocol.json`, `closed-sets.json`, `consolidation.md` sections 3 and 4, and rulings K1 to K9.

Method: a script (scratchpad `B-8.2b/extract.py`) pulled every exit-code statement (622 hits, 581
distinct lines), every stop-reason literal (155 hits), every back-ticked token on a line that speaks
of a stop reason (79 hits) and every bracketed label (4,017 hits, filtered to output labels) into
tables keyed by feature. All 581 exit lines were read against the tables of §E.4, §F.8 and §G.4.
Further `grep` passes covered run-state tokens, quota classes, confidence values, `retryable`, and
the `SPECSTRIDE-*` labels. The two relaunch classifier tables of feature 123 were read row by row.
Every finding was checked in the file it cites.

## Summary

| Severity | Count |
|---|---|
| critical | 1 |
| high | 2 |
| medium | 6 |
| low | 2 |

What holds: every exit code a feature states is a code that feature 100 defines for that process
or command; no feature invents a stop reason; all 15 members of the enumeration are named with the
spelling, exit code and `retryable` of annex E §E.3 wherever a feature states them; run states,
quota classes (nine) and confidence values (five) follow the annexes; the known points (122, 104,
CQ-020, CQ-023) are as recorded.

The three most serious findings:

1. B-8.2b-001: table 1 of feature 123 (`relaunch-observe`) has no signal for `retryable` or for a
   blocked reason, so it relaunches a run that rests blocked on a human, against F123-FR-030 and
   F100-FR-163.
2. B-8.2b-002: feature 123 defines `[SPECSTRIDE-LAUNCH]`, `[SPECSTRIDE-STOP]` and
   `[SPECSTRIDE-DIGEST]` with keys other than those annex G §G.3 fixes for the same labels.
3. B-8.2b-003: features 122 and 123 both claim `[SPECSTRIDE-STATE]` for different lines.
