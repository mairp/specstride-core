# B-8.3d — Constitution review: plans of features 134 to 149

Reviewer: independent agent. Date: 2026-09-29.

Scope: the plans of twelve features (134, 138, 140, 141, 142, 143, 144, 145, 146, 147, 148, 149) against
the constitution v3.0.0 (`.specify/memory/constitution.md`, principles I to XX, Additional Constraints,
Development Workflow and Quality Gates, Governance), the Constitution Check of
`.specify/templates/plan-template.md`, and the plan of feature 100.

Method: every `plan.md` of the twelve features and the plan of feature 100 were read in full. The
`tasks.md` of 134, 138, 140, 143, 144, 145, 146, 147, 148 and 149 were read in full; those of 141 and 142
were read by heading and searched by pattern (language, macOS, release, paid, package paths). A script
printed, for every row of every Constitution Check, the text of each requirement the row cites, so that
each "pass" was read against the requirement behind it. A second script compared the rows of each second
part of a split with the rows of its first part. Tasks were counted with
`grep -cE '^\s*- \[[ xX]\] T[0-9]+'`. `specs/100-specstride/contracts/data/package-graph.json` was read for
every package a plan names. Rulings 18, 32, 34, 56, 61, 67, D1, D2, P1 to P16 were read in `APPROVAL.md`.
Scripts are in the scratch directory `B-8.3d/`. No file other than this report was written.

## Summary

| Severity | Count |
|---|---|
| critical | 1 |
| high | 2 |
| medium | 7 |

What holds: all twelve plans have a Constitution Check that answers all twenty principles; no plan admits
a violation, and none needs a Complexity Tracking row for a waiver of II, III or XVIII. All twelve state
TypeScript 5.x strict on Node.js 22 or later and add no dependency from npm beyond the validator of
feature 100. No row of a second part cites a requirement id of its first part, and no cited requirement
id is missing from its `spec.md`. Every feature that carries as-is behaviour has parity test tasks, and
every feature has characterization or own test tasks. No task builds a second language into the product,
a closed harness list, a critic with tools, or a test that calls a paid service; paid probes are marked
as such and are not run by the build.

The three most serious findings:

1. B-8.3d-001: the prime adapter (138) marks Principle VIII as passed, but its proposer call switches
   off no auto-loaded context and uses the real home at auth tier 2.
2. B-8.3d-002: the plans of 134 and 138 place the pi adapter, the reader and the dialect rows in
   different packages, and 134 names a package that does not exist.
3. B-8.3d-003: the plans of 144 and 147 create packages that the package graph of feature 100 does not
   hold.
